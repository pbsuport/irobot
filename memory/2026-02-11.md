## Codespace 保活设置

Xiaofei 想要防止 Codespace 自动关闭：

1. **Idle Timeout**: GitHub Codespaces 默认 30 分钟
   - 需要在 https://github.com/settings/codespaces 设置为 4 小时
   - API 无法直接修改单个 Codespace 的 idle timeout

2. **创建了 Heartbeat Cron Job**:
   - Job ID: `486f97fa-a171-4902-9fe1-736c0973c86c`
   - 名称: Codespace Heartbeat
   - 间隔: 每 3 小时
   - 功能: 执行命令保持 Codespace 活跃

3. **Free Tier 限制**:
   - 120 core-hours/月 (2-core = 60 实际小时)
   - 15 GB 存储
   - Idle 时间也计入配额

## Oracle Cloud Free Tier 讨论

Xiaofei 询问如何从 WhatsApp 唤醒已关闭的 Codespace。结论：不可能，因为 OpenClaw 随 Codespace 一起关闭。

推荐方案：**Oracle Cloud Free Tier**
- 4 OCPU ARM + 24 GB RAM (永久免费)
- 200 GB 存储
- 可 24/7 运行 OpenClaw
- 支持 WhatsApp 远程唤醒其他服务

对比了 Google Cloud 选项（Cloud Run, Cloud Shell）- 都不适合运行 OpenClaw，因为需要持久连接。

提供了详细的 Oracle Cloud 设置指南。
